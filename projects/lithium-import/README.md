# 한국 수산화리튬 수입 의존도와 공급망 다각화 | Tableau

**분야:** 에너지 소재 · 원자재 공급망 · 데이터 시각화  
**자료 유형:** 3조 Tableau 패키지 통합 문서 `3조 - 태블루.twbx` (사용자 제공, 내부 구조 확인)  
**상태:** 대시보드와 시뮬레이션 구성 확인. 팀 내 개인 기여도, 최종 결론 및 수치 해석은 추가 확인 필요.

## Why · 분석 질문
- 한국의 수산화리튬 수입 구조는 어떤 국가에 집중되어 있을까?
- 중국 의존도는 연도에 따라 어떻게 달라질까?
- 중국 수입 물량 일부를 다른 국가로 전환한다면 의존도와 조달비용은 어떻게 달라질까?

## What · 실제 Tableau 파일에서 확인한 구성
작업 파일 `진짜_최종본.twb`에 **워크시트 13개**와 **대시보드 2개, 스토리 1개**가 있습니다.

1. **글로벌 공급망 분석**: 공급국 지도, 중국 의존도 추이, 선택 연도 국가별 수입량·단가, 중국 의존도 KPI
2. **공급망 다각화**: 대체 공급국 선택, 중국 수입 물량 전환(%), 추가 비용(USD/kg) 조건을 활용한 시뮬레이터
3. **전환 시나리오 비교**: 전환 전후 수입 물량과 공급국 지도, 조달비용 증감, 변경된 중국 의존도, 대체국 가격 비교

### 사용한 데이터와 지표
- 파일에 기록된 출처: **관세청 ‘품목별 국가별 수출입실적(GW)’ 오픈 API / 공공데이터포털, 2026-10-29 인출**
- 내부 원천 데이터 이름에는 연도별·월별 API, 국가별 실적, 2022–2025년 국가 지도, 2025년 전환 시나리오 등이 포함됩니다.
- 분석 지표: 국가별 수입량(kg/ton), 수입금액(USD), 수입단가, 중국 의존도, 전환 물량, 예상 조달비용 증감

## How · 검토할 방법과 한계
`P_Year`, `P_Target`, `P_Transfer`, `P_Extra` 등 Tableau 매개변수를 사용해 연도·대체국·전환 비율·추가 비용 조건을 변경하도록 구성되어 있습니다.

**주의:** 여기서는 제공된 패키지의 구조와 계산 필드 존재를 확인했습니다. Tableau 화면에서 모든 시나리오를 직접 실행해 결과를 검증한 것은 아니므로 **절감액, 의존도 개선 폭, 통계적 인사이트 등을 임의로 제시하지 않습니다.** 또한 원본 파일을 이 GitHub 저장소에 업로드한 상태는 아닙니다.
