# 금융·주식·시계열 분석 | 학습 관심 분야

**상태:** 학습 방향 정리. 완성된 분석 결과물은 확인되지 않았습니다.

기존 [dff 저장소](https://github.com/hibixby001-commits/dff) README에서 작성했던 관심 분야를 통합했습니다.

- 주식 데이터: 수익률, 변동성, 가격 추이
- 시계열 분석: 추세, 계절성, 예측의 한계
- 통계 분석: 기술통계, 상관관계, 가설검정
- 데이터 시각화: 숫자 패턴의 설명

관심 도구: Python, pandas, NumPy, Matplotlib 등
