# Python · Git 실습 기록 (통합 보관본)

원본: [python-study](https://github.com/hibixby001-commits/python-study)

이 폴더는 원본 저장소의 실제 실습 코드를 복사한 보관본입니다. 완성된 데이터 분석 프로젝트는 아닙니다.

- [main.py](./main.py): Python 출력 실습
- [df/main.ipynb](./df/main.ipynb): Jupyter 출력 실습
- [.gitignore](./.gitignore): 가상환경·환경변수 제외 규칙

학습한 명령: `git init`, `add`, `commit`, `status`, `remote`, `pull`, `push`, `reset`, `amend`.

**주의:** 현재 파일 내용만 복사했으며 이전 저장소의 Git 커밋 이력은 옮기지 않았습니다.
